# Photos for the Darkroom

Put photos (JPG or PNG) in this folder and list their file names in `PHOTO_FILES`
near the top of the Darkroom block in `../main.js`, for example:

    const PHOTO_FILES = ['beach.jpg', 'grandma.png'];

They hang on the drying lines in the order listed and develop, in the darkroom's two-ink
print style, as the moth flutters near them. Up to 14 fit on the lines; more are added below.

You can also try photos without changing any files: in the Darkroom, press "Add photos".
Those stay only for that visit.
