# Drawing model

`informative_drawings.onnx` is the *anime style* generator from **Informative Drawings:
Learning to generate line drawings that convey geometry and semantics**
(Caroline Chan, Frédo Durand, Phillip Isola, CVPR 2022),
https://github.com/carolineec/informative-drawings — released under the MIT License.

This ONNX export was published by josephrocca at
https://huggingface.co/rocca/informative-drawings-line-art-onnx and is used unchanged.
It runs in the browser with ONNX Runtime Web; the photo never leaves the phone.
